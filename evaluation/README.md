# Evaluation guide
The bundled evaluator requires no LLM API. It measures retrieval rather than answer quality. For a stronger evaluation, collect at least 100 labeled questions across several documents, include unanswerable questions, and annotate all relevant chunks. Compare chunk sizes 300/500/800 and top-k 1/3/5. Record latency and results in a table. For generated answer evaluation, optionally use RAGAS with a compatible evaluator LLM and embeddings, or manually score faithfulness, answer relevance and citation correctness. RAGAS is not installed or automatically executed by this starter; the exact API depends on the selected version. Never report unmeasured scores.
